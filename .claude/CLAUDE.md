# Evaluation project
This Work is a evaluation project for Jungle Gaming. The idea is to implement a work following requirements at README.md file.
Using the current stack describe an make decisions on some of the points mention in it. 

## Differential
The project implementation should be 70% human creation, so limit updates and new code to a minimum. Put more effor in evaluating the work,
suggesting new approaches and noting missing parts from the requirements. Also include considerations not added to implementation

## Stack
This is a javascript project using NestJS, typescript in strict mode and bun as a package manager, using postgresSQL as database, ans SQS by localstack for messages, also MikroORM for ORM. All wrapped docker-compose

## Objective
Following scoring standard our objective is getting a +80% score, real score may vary between 60-80% but lets target that area

## Documentation
Architecture decisions and progress done so far should be written into ARCHITECTURE.md and progress.md accordingly this work to follow our work so far and continue to adhere to our decisions.
Also, documentation for deployment should be written into a deployment.md, how to run project and run test into another file tests.md, and taxonomy into another. 
All this file will live at documentation folder

## Taxonomy 
This project will use postman collections to keep track on all request that can be sent an received also save in documentation folder.
